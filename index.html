What the company does

The company provides IT security consultancy: penetration testing of desktop applications and external infrastructure, plus kernel-level anti-cheat consulting for game developers and anti-cheat vendors.

All work is done on software and systems owned by the company's clients, with a written agreement and explicit authorisation from the owner for each engagement.

Services

Three areas, each scoped per engagement and reported in plain language with clear steps to fix what was found.

External infrastructure

Testing of what your organisation exposes to the internet, the way an outside attacker would see it.

  • Internet-facing servers
  • Firewalls
  • VPN gateways
  • Email and DNS

Desktop applications

Security testing of Windows software: how it handles input, stores data, talks to its back end and holds up against a local attacker.

  • Installers, services and update paths
  • Local privilege boundaries
  • Client and server communication

Anti-cheat consulting

Helping game studios and anti-cheat vendors assess and harden their protection, including kernel-level components.

  • Review of existing protection
  • Kernel-level design and hardening
  • Findings prioritised by real-world impact

How engagements work

The same five steps, in the same order, every time.

  1. Scope

    We agree which systems are in scope, what is off limits and when testing happens.

  2. Written authorisation

    The system owner signs off in writing before any testing starts.

  3. Testing

    Testing stays inside the agreed scope and time window.

  4. Report

    You get findings ranked by risk, with evidence and concrete fixes.

  5. Retest

    Once fixes are in place, we check that they hold.

Authorised work only

We only test systems the client owns. If you can't authorise testing of a system, we won't test it.

  • Every engagement has a written agreement.
  • The owner of each system gives explicit authorisation.
  • Nothing outside the agreed scope is tested.
  • Findings are shared only with the client.
